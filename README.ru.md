# Sketchybar App Font

Иконочный шрифт для [sketchybar](https://github.com/FelixKratz/SketchyBar), собираемый локально
из набора SVG-иконок.

Каждый глиф привязан к имени приложения, которому принадлежит, поэтому айтем sketchybar может
отрисовать иконку, просто выведя имя приложения этим шрифтом — без таблицы соответствий и
скриптов-маппингов.

[English](README.md)

## Требования

- macOS
- [sketchybar](https://github.com/FelixKratz/SketchyBar), доступный в `PATH`
- Node.js

## Использование

```bash
npx @aimuzov/sketchybar-app-font
```

Команда собирает шрифт и устанавливает его за один проход:

1. собирает встроенные иконки из `icons/`, затем пользовательские из
   `~/.config/sketchybar-icons` (если такая директория есть);
2. строит из них `Sketchybar App Font.ttf`;
3. копирует шрифт в `~/Library/Fonts`;
4. выполняет `sketchybar --reload`, чтобы бар подхватил новый шрифт;
5. удаляет свои временные директории.

Запускайте её заново после каждого добавления или изменения иконки.

## Подключение шрифта в sketchybar

Задайте шрифт тому айтему, который должен показывать иконки приложений, и передайте ему имена
приложений строкой:

```lua
local space = sbar.add("space", {
  label = { font = "Sketchybar App Font:Regular:16" },
  space = 1,
})

space:subscribe("space_windows_change", function(env)
  local apps = ""

  for app in pairs(env.INFO.apps) do
    apps = apps .. app .. " "
  end

  space:set({ label = { string = apps } })
end)
```

Поскольку глифы привязаны к именам приложений, `env.INFO.apps` можно передавать как есть.

## Добавление своих иконок

Положите SVG в `~/.config/sketchybar-icons` и запустите команду ещё раз:

```bash
mkdir -p ~/.config/sketchybar-icons
cp ~/Downloads/MyApp.svg ~/.config/sketchybar-icons/
npx @aimuzov/sketchybar-app-font
```

**Имя файла должно в точности совпадать с именем приложения** — именно оно становится глифом.
Используйте имя в том виде, в каком его сообщает система, а это не всегда то имя, которое видно
в Dock (отсюда `Steam Helper.svg` и `wezterm-gui.svg` среди встроенных иконок).

Пользовательские иконки применяются поверх встроенных, поэтому файл с тем же именем
переопределяет встроенную иконку. Так можно поменять любую иконку, не форкая репозиторий.

При сборке иконки нормализуются — масштабируются в единый em-квадрат и получают одинаковую
ширину, поэтому исходники с разными `viewBox` всё равно выравниваются в баре.

## Как добавить иконку в репозиторий

Положите SVG в `icons/` и закоммитьте по конвенции, принятой в истории проекта:

```
feat(<app>): add icon
```
